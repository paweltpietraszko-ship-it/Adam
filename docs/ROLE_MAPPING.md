# Role mapping

This project is relevant to AI evaluation work because the practical tasks map to common evaluator responsibilities:

| Project activity | Evaluation skill |
| --- | --- |
| Comparing independent model answers | Side-by-side model output evaluation |
| Preserving minority positions | Avoiding naive consensus bias |
| Blind A/B/C judging | Bias-aware evaluation design |
| Tracking contradictions and uncertainty | Failure-mode analysis |
| Checking fresh external context | Grounding evaluation |
| Testing uploaded/contextual instructions | Adversarial testing |
| Converting repeated failures into checks | Regression-oriented evaluation |
| Using backend gates for hard rules | Deterministic guardrails around LLMs |
| Keeping human approval outside the model | Human-in-the-loop quality control |

This mapping describes practical overlap. It does not claim paid RLHF, SFT, annotation or ML engineering experience.
